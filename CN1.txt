Computer Networks
A computer network is a group of interconnected nodes(devices) that share resources and information via communication links.

Node   
A node is a device capable of sending and receiving data.
End nodes- PC, Printer, Server, SmartPhone
Intermediary Nodes- Router, Bridge, Modem
End nodes- uses the data.
Intermediary nodes- forwards the data.

Communication Link  
A communication link is a medium to transfer data.
Types:
Wired(coaxial cables)
Wireless(Wi-fi, Bluetooth etc.)

Uses of a Computer Networks
Communication
Resource Sharing
Remote Access
Collaboration
Education
E-commerce
Entertainment

Characteristics of Computer Networks
1.Fault Tolerance(Continues to work despite failures).
2.Scalability(Add devices without degrading performance).
3.Quality Of Service(Network works smoothly without delays).
4.Security(Protection of data from unauthorized access).

Services offered by Computer Networks
E-mail
Instant messaging
Video-Telephony
Storage Service
Online Games
File Sharing 
Web browsing
VOIP(Voice over Internet Protocol)etc.

Protocol
Protocol is a set of rules for effective communication.
The sender and receiver follow a common set of rules to communicate.
A protocol generally contain information about sender, receiver and communication media.

Elements of a protocol
Message Encoding 
Message Formatting and Encapsulation
Message Size
Message Timing
Message Delivery Options
