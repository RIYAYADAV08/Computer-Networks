Computer Networks
A computer network is a group of interconnected nodes(devices) that share resources and 
information via communication links.

Node
A node is a device capable of sending and receiving data.
End Nodes- PC, Printer, Server, SmartPhone
Intermediary Nodes- Router, Bridge, Modem
End nodes uses the data.
Intermediate nodes forwards the data.

Communication link
A communication link is a medium to transfer data.
Types: Wired(Coaxial Cables)
Wireless(Wifi, Bluetooth etc.)

Uses of Computer Networks

Characteristics of Computer Networks
Fault Tolerance(Continues to work despite failures)
Scalability(Add devices without degrading performance)
Quality Of Service(Network works smoothly without delays)
Security(Protection from Unauthorized access)

Protocol
Protocol is a set of rules for effective communication.
The sender and receiver follow a common set of rules to communicate.
Protocol generally contain information about: sender, receiver and communication Media

Elements of a Protocol are:
Message Encoding
Message Formatting and Encapsulation
Message Size
Message Timing
Message Delivery Options

Types Of Data Flow:
Simple Duplex-One way communication(e.g Keyboard-> CPU)
Half Duplex-Two way communication but only one direction at a time(e.g Walkie-Talkie)
Full Duplex-Two way communication simultaneously(e.g Telephone).
