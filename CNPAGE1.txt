Computer Networks
A computer network is a group of interconnected nodes(devices) that share resources and information via communication links.

Node   
A node is a device capable of sending and receiving data.
End Nodes - PC, Printer, Server, SmartPhone.
Intermediary Nodes - Router, Bridge, Modem.

End node uses the data.
Intermediary nodes forwards the data.

Communication links
A communication link is a medium to transfer data.
Types:
Wired(coaxial cables)
Wireless(WiFi, Bluetooth etc.)

Uses of Computer Networks
Communication
Resource Sharing
Remote Access
Collaboration
Entertainment
Education 
E-commerce

Characteristics of Computer Networks
Fault Tolerance(Continues to work despite failures).
Scalability(Add devices without degrading performance.)
Quality of Service(Network works smoothly without delays)
Security(Protection of data from unauthorized access).

Services Offered by Computer Networks
E-mail
Instant messaging
Video Telephony
Online games
Web browsing
File Sharing
Storage Service
VOIP(Voice over Internet Protocol)

Protocol
Protocol is a set of rules for effective communication.
The sender and receiver follow a common set of rules to communicate.

The protocol generally contain information about:
Sender  
Receiver            
Communication Media

The elements of a protocol are :
1.Message Encoding
2.Message Formatting and Encapsulation
3.Message Timing 
4.Message Size
5.Message Delivery options
